# Expense Management Dashboard

A browser-based personal expense management dashboard built with plain HTML, CSS, and JavaScript.

## Overview
This project helps track personal finances from a single dashboard with local browser storage and no backend dependency.

## Current Features
- Login flow and protected dashboard shell
- Bank account management
- Income, expense, and self-transfer tracking
- Recurring payments management
- SIP and investment tracking
- Loan EMI tracking
- Monthly and category budget monitoring
- Dashboard summary cards for balances, income, expenses, SIPs, EMIs, and upcoming items
- LocalStorage-based persistence
- Mobile-responsive layout

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
- localStorage

## Run Locally
1. Clone or download the repository.
2. Add the required frontend files to the project root.
3. Open `index.html` directly in a browser.

## Notes
- This project is frontend-only.
- Data is stored locally in the browser.
- Sensitive credentials are intentionally not documented in this repository.
